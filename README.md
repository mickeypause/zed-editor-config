# Zed Editor Config

My personal Zed editor configuration files.

## Files

- `keymap.json` - Custom keybindings
- `settings.json` - Editor settings

## Installation

To restore on a new machine:

```bash
# Clone this repo
git clone https://github.com/mickeypause/zed-editor-config.git

# Copy config files to Zed config directory
cp zed-editor-config/keymap.json ~/.config/zed/
cp zed-editor-config/settings.json ~/.config/zed/
```

## Custom Keybindings

| Shortcut | Action |
|----------|--------|
| `cmd+b` | Toggle Right Dock |
| `cmd+i` | Toggle Left Dock (AI Panel) |
| `cmd+k w` | Close All Files (VSCode style) |
